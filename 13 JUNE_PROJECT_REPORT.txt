# Description

GameVault DB is a MongoDB-based REST API designed to manage a digital games library ecosystem. The system tracks games, developers, publishers, players, game genres,
player libraries, reviews, and achievements.

The project is built using Node.js, Express.js, and MongoDB and demonstrates CRUD operations, REST API development, database connectivity, and relationship mapping
(One-to-One, One-to-Many, Many-to-One, and Many-to-Many).

# REST API Modules

1. Game Management                     2. Developer Management

Operations:                            Operations:

POST   /game                           POST   /developer
GET    /games                          GET    /developers
GET    /game/:id                       GET    /developer/:id
PUT    /game/:id                       PUT    /developer/:id
DELETE /game/:id                       DELETE /developer/:id

Purpose:                               Purpose:

Create Games                           Manage Developer Information
View Games
Update Games
Delete Games


3. Publisher Management                4. Genre Management

Operations:                            Operations:

POST   /publisher                      POST   /genre
GET    /publishers                     GET    /genres
GET    /publisher/:id                  GET    /genre/:id
PUT    /publisher/:id                  PUT    /genre/:id
DELETE /publisher/:id                  DELETE /genre/:id

Purpose:                               Purpose:

Manage Publisher Organizations         Manage Game Genre Categories


5. Player Management                   6. Player Library Management

7. Review Management                   8. Achievement Management

Operations:                            Operations:

# Relationship Mapping

One-to-One
Game ↔ Developer (Lead Studio)

One-to-Many
Publisher → Games

Many-to-One
Reviews → Game

Many-to-Many
Players ↔ Games (via Player Library)
